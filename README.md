# projeto_5
### 🚗 Dashboard de Análise de Vendas de Carros
Este projeto é um aplicativo web interativo desenvolvido em Python para a análise exploratória de dados de anúncios de vendas de veículos nos EUA. O objetivo é fornecer uma interface simples e funcional para visualizar tendências de quilometragem e preços, utilizando ferramentas modernas de desenvolvimento de software.

Link do Aplicativo no Render:https://projeto-5-2cxw.onrender.com/


### 🛠️ Ferramentas Utilizadas
Linguagem: Python 3.9+

Bibliotecas Principais:

Streamlit: Para a criação do dashboard web.

Pandas: Para manipulação e limpeza dos dados.

Plotly Express: Para geração de gráficos interativos.

Ambiente e Deploy:

VS Code: Editor de código.

Git/GitHub: Controle de versão.

Conda/Virtualenv: Gerenciamento de ambientes virtuais.

Render: Serviço de hospedagem em nuvem (PaaS).

### 📈 Funcionalidades do Aplicativo
O dashboard oferece ferramentas interativas para explorar o conjunto de dados vehicles_us.csv:

Visualização de Histograma: Permite analisar a distribuição da quilometragem (odometer) dos veículos anunciados.

Gráfico de Dispersão: Explora a relação entre o preço dos veículos e a quilometragem, facilitando a identificação de correlações e outliers.

Interatividade: O usuário pode gerar os gráficos sob demanda através de botões ou caixas de seleção específicos.
